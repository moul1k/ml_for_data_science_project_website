# Exoplanet Research Website

**Moulik Kumar**

Project Assignment 1 — Machine Learning for Data Science

[View the working website](https://moul1k.github.io/ml_for_data_science_project_website/)

This project explores confirmed planets beyond our Solar System, including their physical properties, orbital characteristics, host stars, discovery methods, and patterns in the known population.

The primary data comes from the [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/). A supplementary Open Exoplanet Catalogue download is retained for provenance but is not merged into the analysis.

## Repository structure

```text
├── code/       Python scripts for collection, cleaning, and analysis
├── data/       Raw and processed exoplanet datasets
├── figures/    Charts and data-preview images
├── reports/    Statistics, metadata, and cleaning summaries
├── py/         Space for additional Python files
├── index.html  Website content
├── style.css   Website styling
└── script.js   Website interactions
```

See [`code/README.md`](code/README.md) for instructions to install the Python dependencies and run the analysis pipeline.
